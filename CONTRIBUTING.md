# Contributing

Keep changes within the current milestone. Run the test, typecheck and production build commands from README.md before opening a pull request.

Use named latitude and longitude fields outside the Leaflet adapter. Do not add location analytics, route logging, tile prefetch, or a background location watcher. Add lifecycle tests when changing permission handling or GPS subscriptions.

For interface changes, check both a narrow phone viewport and desktop. Include screenshots and describe any changed keyboard behavior.
